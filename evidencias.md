# Evidencias - TP1

## 1. Push directo a main rechazado
![Push rechazado](img/push-rechazado.png)
GitHub rechaza el push directo porque la regla de protección sobre `main` está activa e incluye al dueño del repositorio.

## 2. Aviso de conflicto en el Pull Request
![Aviso de conflicto](img/aviso-conflicto.png)
GitHub alerta que el PR de la rama B no se puede mergear automáticamente por tocar las mismas líneas que la rama A.

## 3. Marcadores de conflicto
![Marcadores de conflicto](img/marcadores-conflicto.png)
Vista de los marcadores `<<<<<<<`, `=======` y `>>>>>>>` en el editor web durante la resolución manual.

## 4. Release v1.0.0 publicada
![Release publicada](img/release-v1.0.0.png)
Publicación de la versión en la sección de Releases sobre el tag `v1.0.0`.
